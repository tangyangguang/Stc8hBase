# H8K64U OTA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first STC8H8K64U-only OTA foundation: transport-neutral OTA core, H8K64U IAP program-area backend, RS485/UART-passthrough transport adapter, and safe examples/tests.

**Architecture:** Keep OTA core independent from UART/RS485/433. The core validates a manifest, accepts sequential chunks, delegates erase/write/read to an explicit backend, verifies CRC32, and commits dual metadata records. RS485 and 433 UART-passthrough only wrap bytes into OTA frames and feed the same payload-level API.

**Tech Stack:** SDCC mcs51, Keil C51-compatible C89 style, PlatformIO examples, existing `tools/check_host_tests.sh`, `tools/check_examples.sh`, host C tests with `cc`.

---

## Scope

This plan implements only `STC8H8K64U-45I-LQFP48` OTA. It does not implement STC8H full-family OTA, internal A/B images, bootloader self-update, SPI/register 433 drivers, Modbus, cloud download, signature verification, or application business logic.

```c
#include "util_crc32.h"

stc8h_u32 util_crc32_ieee_update(stc8h_u32 crc, const stc8h_u8 *data, stc8h_u16 len)
{
    stc8h_u16 i;
    stc8h_u8 bit;

    crc = ~crc;
    for (i = 0u; i < len; ++i) {
        crc ^= (stc8h_u32)data[i];
        for (bit = 0u; bit < 8u; ++bit) {
            if ((crc & 1UL) != 0UL) {
                crc = (crc >> 1) ^ 0xEDB88320UL;
            } else {
                crc >>= 1;
            }
        }
    }
    return ~crc;
}

stc8h_u32 util_crc32_ieee(const stc8h_u8 *data, stc8h_u16 len)
{
    return util_crc32_ieee_update(0UL, data, len);
}
```

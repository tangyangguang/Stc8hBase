# H8K64U OTA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first `STC8H8K64U-45I-LQFP48`-only OTA foundation with a transport-neutral OTA core, canonical wire formats, safe metadata persistence, H8K64U IAP program-area backend, RS485 reference transport, and UART3 passthrough transport for 433-style transparent serial modules.

**Architecture:** ESP32 owns cloud download, full-image staging, signature/hash verification, retry policy, and upgrade orchestration. STC8H8K64U owns a permanent boot stub/bootloader, canonical manifest/frame decoding, sequential chunk writing, CRC32 verification, dual-record boot metadata, application jump, and recovery/retry when the single application area is not valid. RS485 and UART3 passthrough transports only move OTA frames and feed the same payload-level OTA API.

**Tech Stack:** SDCC mcs51, Keil C51-compatible C89 style, PlatformIO examples, existing `tools/check_host_tests.sh`, `tools/check_examples.sh`, host C tests with `cc`, and H8K64U hardware validation only after explicit destructive-write confirmation.

---

## Scope

This plan implements only `STC8H8K64U-45I-LQFP48` OTA.

Included:

- Single application area at `0x0200..0xEFFF`.
- Boot stub/vector area at `0x0000..0x01FF`.
- Bootloader area starting at `0xF000`, subject to final linker size check.
- Dual boot parameter records at `0xFC00..0xFDFF` and `0xFE00..0xFFFF`.
- RS485 reference transport over `BOARD_RS485_UART`.
- 433-style transparent serial transport over `BOARD_RF433_UART`/UART3.

Excluded:

- STC8H full-family OTA.
- `STC8H1K08` program OTA.
- Internal A/B image rollback.
- Bootloader self-update.
- SPI/register-based 433 modules.
- Modbus business protocol.
- Cloud download, signature verification, or irrigation business logic in the base library.

## Public API Baseline

Keep the API small and compile-time optional. When OTA is disabled, these declarations and implementation objects must not be pulled into the application.

```c
typedef enum {
    STC8H_OTA_BOOT_ACTION_STAY_BOOTLOADER = 0,
    STC8H_OTA_BOOT_ACTION_JUMP_APP,
    STC8H_OTA_BOOT_ACTION_TRIAL_APP
} stc8h_ota_boot_action_t;

void stc8h_ota_init(stc8h_ota_context_t *ctx, const stc8h_ota_backend_t *backend, stc8h_ota_params_store_t *params_store);
stc8h_status_t stc8h_ota_manifest_decode(const stc8h_u8 *bytes, stc8h_u16 len, stc8h_ota_manifest_t *manifest);
stc8h_status_t stc8h_ota_params_decode(const stc8h_u8 *bytes, stc8h_u16 len, stc8h_ota_params_t *params);
stc8h_status_t stc8h_ota_params_encode(const stc8h_ota_params_t *params, stc8h_u8 *bytes, stc8h_u16 len);
stc8h_u8 stc8h_ota_should_enter_bootloader(const stc8h_ota_params_t *params);
stc8h_ota_boot_action_t stc8h_ota_get_boot_action(const stc8h_ota_params_t *params);
stc8h_status_t stc8h_ota_begin(stc8h_ota_context_t *ctx, const stc8h_ota_manifest_t *manifest);
stc8h_status_t stc8h_ota_write_chunk(stc8h_ota_context_t *ctx, stc8h_u32 offset, const stc8h_u8 *data, stc8h_u16 len);
stc8h_status_t stc8h_ota_verify(stc8h_ota_context_t *ctx);
stc8h_status_t stc8h_ota_commit(stc8h_ota_context_t *ctx);
stc8h_status_t stc8h_ota_abort(stc8h_ota_context_t *ctx, stc8h_u8 reason);
stc8h_ota_state_t stc8h_ota_get_status(const stc8h_ota_context_t *ctx);
stc8h_status_t stc8h_ota_mark_boot_attempted(stc8h_ota_params_store_t *store);
stc8h_status_t stc8h_ota_mark_app_valid(stc8h_ota_params_store_t *store);
```

Use 16-bit addresses for STC code-space addresses. Use 32-bit values only for image size, offset, CRC32, and version flags where required.

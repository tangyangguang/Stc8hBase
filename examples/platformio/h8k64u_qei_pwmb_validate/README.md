# H8K64U PWMB 正交编码器验证

这个 PlatformIO 示例只验证 `STC8H8K64U-45I-LQFP48` 的 PWMB 硬件正交计数，不包含电机、位置控制或业务协议。

## 配置

- `TI5`: `P2.0/PWMB5`，`pin_select=0`。
- `TI6`: `P2.1/PWMB6`，`pin_select=0`。
- encoder mode 3：两个输入的有效边沿都参与硬件计数。
- 输入数字滤波编码 `2`：官方表中的 4 个采样时钟。
- P2.0/P2.1 由示例显式配置为高阻输入。

示例持续把 16 位原始计数写入 `qei_sample`，便于调试器或后续板级验证读取。HAL 不启用中断，也不维护软件累计位置。

## 构建

```sh
pio run
```

构建命令不会烧录硬件。需要烧录时仍使用 PlatformIO 入口：

```sh
pio run -t upload --upload-port /dev/cu.usbserial-xxx
```

## 硬件验证

1. 确认编码器输出电平、上拉和保护电路适配 5V MCU 输入。
2. 静止时确认 `qei_sample` 稳定。
3. 分别正转和反转，确认计数方向相反。
4. 验证跨 `0xFFFF/0x0000` 回绕时，应用按 16 位模差计算仍连续。
5. 在真实最高转速下检查漏计和乱向，再冻结倍率、滤波和最大输入频率。

mode 3 是当前台架起点，不等于已经通过实测冻结的 x4 产品倍率。

## 资源边界

本示例占用整个 `PWMB` 计数器和通道 5/6。不能同时把 `PWMB5..8` 用作 PWM 输出；`PWMA` 不受影响。
